## 正在探索

<sub>RESEARCH LOG / 持续推进中的问题</sub>

#### 猫类意图识别

从音频、姿态与多模态融合探索猫类意图。负责课题定义、技术路线、数据与标签方案；已获学院“创新+”工作站立项，进入数据整理与 baseline 实验阶段。

#### 太阳暗条实例分割

面向 2026 挑战赛的 Hα 图像实例分割研究。已开展多轮基线、分辨率消融、候选误差分析与局部细化，继续补充形态评价和研究文稿。[研究介绍 ↗](https://github.com/by-lastime/solar-filament-showcase)

#### 跨语言提示与中国形象表征

研究不同语言提示下的视觉表征差异与传播偏差，结合多模态主题编码、人工核验、计算美学与统计比较。
